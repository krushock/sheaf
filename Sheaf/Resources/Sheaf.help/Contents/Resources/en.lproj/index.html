Good to know

  • Every change can be undone with ⌘Z, including changes to pages and whole-document tools.
  • Sheaf saves the way Pages does: there is no need to save as you go, and File ▸ Revert To brings back earlier versions.
  • Most changes are added to the end of the file, which keeps saving fast and leaves a digitally signed file's signature intact. Redaction, reducing the file size and setting a password write the file out afresh.
