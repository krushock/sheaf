Convert and export

Word, Excel, rich text, web pages, pictures and PDF/A.

All of these are under File ▸ Export To and File ▸ Export as Images….

Word (Beta)

Carries the text over in paragraphs with its fonts, sizes, colors and pictures, on pages of the same size. Columns, tables and exact positions are not carried over, so expect to tidy the result.

Excel (Beta)

Each page becomes a sheet. Text that lines up in rows and columns lands in cells, and numbers become numbers you can add up. It works best on statements, invoices and price lists.

PDF/A

PDF/A-2b is a form of PDF meant to be readable decades from now. Sheaf puts fonts inside the file, adds a color profile and the required metadata, and removes scripts, attachments and the password. The sheet lists what was done and anything it could not put right.

Sheaf does not certify the result. If the file is going to an archive that checks conformance, run it through their validator as well.

Rich Text, Web Page and Plain Text (Beta)

The text in paragraphs, as for Word, saved as an RTF file for TextEdit and Pages, as a web page, or as plain words. Pictures are left out.

Pictures

File ▸ Export as Images… saves pages as PNG, JPEG, TIFF or HEIC at the resolution you choose.
