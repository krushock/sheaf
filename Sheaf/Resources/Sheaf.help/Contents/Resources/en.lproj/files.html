Sheaf Help

Whole-document tools

Merge, split, shrink, protect, watermark and number.

  • Merge: File ▸ New from PDFs… ⌥⌘N joins PDFs and pictures in the order you list them.
  • From pictures: File ▸ New from Images… ⇧⌘N makes a page from each picture, and can square up photos of paper.
  • Split: File ▸ Split into Documents… by page count, page ranges or bookmarks.
  • Shrink: File ▸ Reduce File Size…. "Keep Everything Exact" only repacks; the other choices also scale down pictures.
  • Protect: File ▸ Set Password… encrypts with AES 256-bit. A forgotten password cannot be recovered.
  • All at once, while saving: File ▸ Save As… and File ▸ Export… have the same choices under the file's name, as Preview does: Create PDF/A, Optimize images for screen, Save images as JPEG and Permissions…. Save As makes the document in the window what was saved; Export writes a copy and leaves the document alone. Export can also write the page being read as a JPEG, PNG, TIFF or HEIC picture.
  • Watermark and Header and Footer are in the Tools menu, with a live preview.
  • Details: File ▸ Document Info… ⌘I shows and changes the title, author and keywords.
