Automate with Flows and Shortcuts

Run the same steps on many files.

Flows

A flow is a saved list of steps, such as "recognize text, then reduce the file size". File ▸ Flows… opens the list.

  • Add steps with Add Step, drag to reorder, and set each step's options on its row.
  • Run on Files…, or drop files on the window, runs the flow on each and saves the results in a folder you choose. The originals are not changed.
  • Tools ▸ Run Flow runs a flow on the open document. One Undo takes it back.

Shortcuts and Quick Actions

  • Sheaf's tools appear in the Shortcuts app as actions: merge, split, reduce, recognize text, convert, watermark, and "Run Flow on Files".
  • In Shortcuts, turn on "Use as Quick Action" for a shortcut to run it from the Finder's right-click menu.
  • The Finder's Services menu has "Merge with Sheaf", "Make PDF with Sheaf" and "Reduce File Size with Sheaf".
