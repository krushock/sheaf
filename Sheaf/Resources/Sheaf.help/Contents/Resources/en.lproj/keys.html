Keyboard shortcuts

The keys worth knowing.

Everywhere

  • ⌘F search, ⌘G next result, ⇧⌘G previous result
  • ⌥⌘F find and replace
  • ⌘1 ⌘2 ⌘3 page layout; ⌘0 actual size; ⌘9 fit width; ⌘8 fit page; ⌘+ ⌘− zoom
  • ⌥⌘1 hide sidebar; ⌥⌘2 thumbnails; ⌥⌘3 table of contents; ⌥⌘4 highlights and notes
  • ⌥↑ ⌥↓ previous and next page; ⌥⌘G go to page
  • ⌘L ⌘R rotate; ⌘D add bookmark; ⌘I document info

Modes

  • ⇧⌘A Select tool; ⇧⌘E edit text and pictures; ⇧⌘M form fields; ⌥⌘O organize pages
  • ⌃⌘I options panel; ⌃⌘U Summary panel; ⇧⌘K compare with another document

With something selected

  • Arrow keys nudge; ⇧ with arrows for bigger steps
  • Return edits text; Esc finishes or deselects; Delete removes
  • Tab and ⇧Tab move to the next and previous field or piece of text

Markup tools

  • ⌃⌘H highlight, ⌃⌘U underline, ⌃⌘S strikethrough, ⌃⌘T text, ⌃⌘N note, ⌃⌘R rectangle, ⌃⌘O ellipse, ⌃⌘A arrow, ⌃⌘D draw, ⌃⌘K link
